# SYSTEM12

نظام متابعة مشاريع المساجد – واجهة React (تجريبية)

## 📌 الوصف
واجهة مبنية بـ React لمتابعة مراحل مشاريع المساجد، تشمل:
- حساب المدد بين المراحل
- عرض الحالة الحالية
- دعم الانتقالات المرحلية
- واجهة عربية

## 🛠️ التقنيات
- React (JSX)
- Framer Motion

## 🚀 التشغيل
الملف حاليًا واجهة فقط، ويحتاج دمجه داخل مشروع React  
(Vite أو CRA).
